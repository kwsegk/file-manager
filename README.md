# 🗂️ Файловый менеджер на JavaFX

Современный и функциональный файловый менеджер, написанный на Java с использованием JavaFX. Проект предоставляет удобный графический интерфейс для работы с файловой системой.

## 📋 Описание

Файловый менеджер с современным интерфейсом, поддерживающий все основные операции с файлами и папками. Приложение имеет интуитивно понятный дизайн в сине-голубых тонах и предоставляет широкий набор инструментов для эффективной работы.

## ✨ Основные возможности

### 🚀 Навигация
- **Breadcrumb навигация** - кликабельные сегменты пути для быстрого перехода
- **Кнопки навигации**: Назад, Вперёд, Вверх, Домой
- **История навигации** - выпадающий список с ранее посещёнными папками
- **Двойной клик** на папку для открытия
- **Поле поиска** для быстрого перехода к папке

### 📁 Операции с файлами
- **Создание** файлов и папок
- **Копирование и вырезание** с буфером обмена
- **Вставка** файлов с автоматическим переименованием при конфликтах
- **Переименование** файлов и папок
- **Удаление** с подтверждением (в том числе множественное)
- **Контекстное меню** (правая кнопка мыши)

### 🎯 Выделение и сортировка
- **Множественное выделение** файлов
  - Ctrl + клик - выбор нескольких файлов
  - Shift + клик - выбор диапазона
- **Сортировка** по колонкам (имя, размер, дата, тип, формат)
- **Иконки файлов** по типу (📁 папки, 🖼️ изображения, 📄 документы и т.д.)

### 🔍 Инструменты
- **Поиск файлов** - рекурсивный поиск с поддержкой масок (*.txt, photo*)
- **Анализ папки** - подсчёт размера, количества файлов и подпапок
- **Hex-редактор** - просмотр любых файлов в шестнадцатеричном формате
- **Текстовый редактор** - встроенный редактор для текстовых файлов

### ⭐ Дополнительно
- **Избранное** - закладки часто используемых папок в боковой панели
- **История операций** - отслеживание всех действий
- **Настройки** - отображение текущих параметров приложения
- **Скрытые файлы** - опция показа/скрытия системных файлов
- **Справка** - полная документация и список горячих клавиш

## 📦 Установка и запуск

### Требования
- JDK 17 или выше
- Maven 3.8 или выше

### Клонирование репозитория
```bash
git clone https://github.com/kwsegk/file-manager.git
cd file-manager
```

### Сборка проекта
```bash
mvn clean install
```

### Запуск приложения
```bash
mvn javafx:run
```

## 🎯 Использование

### Основные операции

**Навигация:**
- Двойной клик на папку → Открыть
- Кнопка "Назад/Вперёд" → История навигации
- Клик на сегмент breadcrumb → Быстрый переход
- Кнопка "Поиск" → Ввод пути вручную

**Работа с файлами:**
1. Выберите файл(ы) в таблице
2. Используйте меню "Правка" или контекстное меню (ПКМ)
3. Выполните нужную операцию

**Множественное выделение:**
- Ctrl + клик → Добавить файл к выделению
- Shift + клик → Выбрать диапазон файлов

**Поиск файлов:**
1. Инструменты → Поиск файлов
2. Введите имя или маску (например: `*.jpg`, `document*`)
3. Просмотрите результаты

**Избранное:**
1. Перейдите в нужную папку
2. Нажмите "+ Добавить" в боковой панели
3. Двойной клик на закладку → Быстрый переход

## 🔧 Настройки

Доступные настройки через меню:
- **Показ скрытых файлов** - Вид → Показывать скрытые файлы
- **История** - Вид → История (просмотр всех операций)
- **Информация** - Файл → Настройки (текущие параметры)
